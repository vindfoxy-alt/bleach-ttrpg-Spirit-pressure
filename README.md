# Spirit Pressure (fan-made TTRPG)

A d20 tabletop RPG of souls, blades and reiatsu: four classes (Soul Reaper, Quincy, Hollowborn, Fullbringer), sixteen subclasses, levels 1-20, separate HP and Reiatsu Points.

- **Site:** https://vindfoxy-alt.github.io/bleach-ttrpg-Spirit-pressure/
- **Player's Handbook:** [Spirit_Pressure_Players_Handbook.pdf](Spirit_Pressure_Players_Handbook.pdf)
- **Game Master's Guide:** [Spirit_Pressure_GM_Guide.pdf](Spirit_Pressure_GM_Guide.pdf)

v0.2, working title.

Independent fan project inspired by *Bleach* by Tite Kubo. Not affiliated with or endorsed by the creator, Shueisha, VIZ Media, TV Tokyo, Studio Pierrot or Wizards of the Coast.
